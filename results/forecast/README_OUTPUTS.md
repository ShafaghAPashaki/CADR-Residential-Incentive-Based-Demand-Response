# Forecast outputs

**Historical local-output inventory, not a list of files distributed with this public release.** The full private run's root forecast directory contained a combined forecast figure, forecast metric files, and an integration-gate file. The combined figure with individual-household traces and private forecast-state inputs are excluded from the public release tree.

In the historical authorised local run, `load/` contained household models, scalers, histories, predictions, diagnostics, and standalone load figures; not all are published.

In the historical authorised local run, `price/` contained the price model, scaler, history, predictions, diagnostics, and the standalone price figure; not all are published.

The final metric table reports MAE only.
